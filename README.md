# Telegram Public Website Asset Collector

Install: `pip install -r requirements.txt`

Set environment variable `BOT_TOKEN` to your BotFather token, then run:
`python bot.py`

Render:
- Create a Background Worker
- Build command: `pip install -r requirements.txt`
- Start command: `python bot.py`
- Environment variable: `BOT_TOKEN` = your Telegram bot token

The bot collects only publicly accessible browser-delivered files from sites you own or are authorized to archive. It cannot recover server-side source code, databases, secrets, login-only content, or bypass access controls.
